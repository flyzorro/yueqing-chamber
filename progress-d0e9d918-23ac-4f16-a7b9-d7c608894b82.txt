## Codebase Patterns
- Express API routes are registered centrally in `server/src/routes/index.ts`, and each resource keeps its own dedicated router file under `server/src/routes/`.
- List endpoints follow a shared response shape with `success`, `data`, `filters`, and `pagination`; fallback-friendly resources can also return `error` explicitly for consistency.
- Data access logic lives in store classes under `server/src/models/`, with non-production Prisma fallback to fixture data when local tables are unavailable (`P2021` / init failures).
- API route tests use Jest + Supertest with `../lib/prisma` mocked directly inside each route test file.
