## 一、功能概述

为乐清商会移动应用实现信息发布功能，支持会员发布商机、供需、通知等信息。

**核心规则**：
- **浏览权限**：所有登录会员可查看信息列表
- **发布权限**：所有登录会员可发布信息
- **删除权限**：仅发布者本人或管理员可删除

**分类体系**：
- 产品、技术、市场、金融、人才、政策、其他

---

## 二、用户价值

| 用户类型 | 获得价值 |
|----------|----------|
| 会员企业 | 发布商机、寻求合作、获取政策信息 |
| 商会运营 | 发布通知、促进会员间交流合作 |
| 访客 | 查看公开信息（需登录后查看完整联系方式） |

## 三、技术实现摘要

### 3.1 后端实现

**数据模型**：`server/prisma/schema.prisma`
```prisma
model Information {
  id           String   @id @default(cuid())
  title        String   @db.VarChar
  content      String   @db.Text
  category     String   @default("other")
  contactname  String?  @db.VarChar
  contactphone String?  @db.VarChar
  publisherid  String   @db.VarChar
  createdat    DateTime @default(now)
  updatedat    DateTime @default(now)
  
  @@index([category])
  @@index([publisherid])
  @@index([createdat])
}
```

**API 端点**：
| 端点 | 方法 | 鉴权 | 描述 |
|------|------|------|------|
| `/api/information` | GET | 需登录 | 获取信息列表（分页 + 分类筛选） |
| `/api/information` | POST | 需登录 | 发布信息 |
| `/api/information/:id` | DELETE | 需登录 | 删除信息（仅管理员或发布者） |

### 3.2 移动端实现

**页面结构**：
- `mobile/app/information.tsx` - 信息列表页（带分类筛选）
- `mobile/app/create-information.tsx` - 信息发布表单页
- `mobile/app/(tabs)/services.tsx` - 服务页入口

**关键交互**：
1. 未登录用户看不到"发布"按钮
2. 发布成功后使用 `router.replace()` 强制刷新列表
3. 返回按钮使用 `router.back()` 依赖 Stack 路由历史

## 四、关键 Bug 修复

### Bug 1: 发布后列表不刷新
**症状**：发布信息后返回列表页，新信息不显示  
**根因**：`router.back()` 返回时页面已挂载，useEffect 不会重新执行  
**修复**：改为 `router.replace('/information')` 强制重新加载页面

### Bug 2: 返回按钮报错 "GO_BACK was not handled"
**症状**：点击返回按钮报导航错误  
**根因**：`information` 和 `create-information` 路由未在 Stack layout 中注册，无导航历史  
**修复**：在 `_layout.tsx` 中注册两个路由

### Bug 3: 无障碍不合规
**症状**：返回按钮触摸区域太小，缺少无障碍语义  
**修复**：
- 添加 `accessibilityRole="button"`、`accessibilityLabel`、`accessibilityHint`
- 添加 `hitSlop={{ top: 10, bottom: 10, left: 10, right: 10 }}` 扩大触摸区域

## 五、设计决策记录

| 决策点 | 选项 | 选择 | 原因 |
|--------|------|------|------|
| 发布权限 | 仅管理员 / 所有会员 | 所有会员 | 降低运营负担，促进会员互动 |
| 审核流程 | 需要审核 / 直接发布 | 直接发布 | MVP 快速上线，后续可加审核 |
| 分类管理 | 固定分类 / 后台可配置 | 固定分类 | 简化实现，7 个分类已够用 |
| 路由命名 | `/infos` / `/information` | `/information` | 全称更清晰，与模型名一致 |

## 九、可复用经验

### 9.1 Expo Router 导航模式

**问题**：`router.back()` 需要 Stack 路由历史存在

**解决方案**：
```typescript
// _layout.tsx 中注册所有需要导航历史的路线
<Stack.Screen name="information" options={{ headerShown: false }} />
<Stack.Screen name="create-information" options={{ headerShown: false }} />
```

### 9.2 发布后刷新列表

**问题**：`router.back()` 不会触发已挂载页面的 useEffect

**解决方案**：
```typescript
// 使用 router.replace() 强制重新加载
Alert.alert('成功', '信息发布成功', [
  { text: '确定', onPress: () => router.replace('/information') },
]);
```

### 9.3 无障碍规范

**触摸区域**：≥ 44x44px（iOS 人机界面指南）

**实现**：
```typescript
<Pressable
  accessibilityRole="button"
  accessibilityLabel="返回上一页"
  accessibilityHint="返回到上一个页面"
  hitSlop={{ top: 10, bottom: 10, left: 10, right: 10 }}
>
  <Text>‹ 返回</Text>
</Pressable>
```
