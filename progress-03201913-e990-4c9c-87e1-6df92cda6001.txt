## Codebase Patterns
- Server uses Prisma schema in `server/prisma/schema.prisma`, and the `server` build step runs `prisma generate && tsc` to refresh Prisma client types before TypeScript compilation.
- Backend tests use Jest with `ts-jest`; API tests follow the pattern of mocking `../lib/prisma` and colocating specs in `server/src/__tests__/`.
- When the local database or table is unavailable in non-production, list data can fall back to fixture files under `server/src/data/`.
